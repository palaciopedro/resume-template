\section{PROJETOS DE DESTAQUE}

\textbf{Estudo do Mercado de Videogames -- Análise de Dados (Python, Pandas, NumPy, Matplotlib)} \\
Projeto de consolidação desenvolvido ao final do Workshop de Análise de Dados do IEEE CS Chapter. Realizou-se a análise exploratória de um dataset com mais de 16.000 registros contendo vendas por região, plataforma, ano de lançamento, gênero e publicadora.
\begin{itemize}
    \item Realização de todo o pipeline de dados: exploração inicial, entendimento das variáveis e identificação de padrões.
    \item Limpeza de dados e tratamento sistemático de valores ausentes e inconsistências.
    \item Criação de métricas de vendas globais/regionais e cálculo de estatísticas descritivas.
    \item Desenvolvimento de visualizações gráficas com Matplotlib para geração de insights sobre tendências do mercado.
\end{itemize}

\textbf{Automação de Planilha + Integração com API -- Python, Pandas, OpenPyXL} \\
Desenvolvimento de aplicação em Python para automatizar a atualização de planilhas Excel integradas a uma API (Tabela do Brasileirão), eliminando processos manuais, preservando a estrutura dos arquivos e gerando executável para distribuição.

\textbf{Connect API – Java, Spring Boot, MongoDB} \\
API REST para interação entre usuários e postagens com suporte a buscas por regex, DTOs, filtros por datas e modelagem NoSQL.

\textbf{API de Gestão de Vendas – Java, Spring Boot, Spring Data JPA} \\
API REST em Java para gestão de pedidos e produtos, utilizando Hibernate/JPA, banco H2/PostgreSQL e arquitetura em camadas.

\textbf{Task Tracker CLI – Python} \\
Aplicação CLI modular em Python para gerenciamento de tarefas (CRUD) com persistência de dados em arquivos JSON.
