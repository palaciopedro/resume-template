\section{Projetos}
\textbf{Website Pessoal - HTML e CSS} \\

\textbf{Task Tracker CLI – Python} \\
Desenvolvimento de aplicação em linha de comando (CLI) para gerenciamento de tarefas, permitindo operações de CRUD (criar, listar, atualizar e remover). Implementação de persistência de dados em arquivo JSON e manipulação de argumentos via terminal sem uso de bibliotecas externas. Código estruturado de forma modular visando organização e manutenibilidade.  

\textbf{Integração JDBC e Banco de Dados – Java e SQL} \\
Desenvolvi uma aplicação em Java utilizando JDBC para realizar a conexão e manipulação de dados em um banco de dados relacional. O projeto implementa operações completas de CRUD. Também foi aplicado gerenciamento adequado de recursos, garantindo o fechamento correto de conexões, statements e result sets. O projeto reforça conceitos fundamentais de back-end, como integração com banco de dados, separação de responsabilidades e tratamento de exceções SQL.

\textbf{Automação de Planilha + Integração com API - Python, Pandas, OpenPyXL} \\
Desenvolvimento de aplicação em Python para automatizar o processo de atualização de planilhas Excel, integrando com uma API que entrega os dados atualizados da Tabela do Brasileirão, eliminando tarefas manuais repetitivas e reduzindo riscos de erro na manipulação de dados. O projeto processa dados por meio de um serviço principal (api_service) e atualiza diretamente uma aba existente, preservando a estrutura original do arquivo sem recriá-lo. Inclui validação de existência de arquivos, organização modular do código e geração de executável (.exe) para distribuição sem necessidade de ambiente Python instalado.
