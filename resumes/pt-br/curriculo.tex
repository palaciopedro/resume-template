\section{Projetos}
\textbf{Safety Inspect – React Native, Expo, TypeScript, Supabase} \\
Desenvolvimento de aplicativo mobile para gestão de inspeções de Segurança e Saúde no Trabalho (SST), permitindo registrar inspeções, documentar ocorrências com fotos e calcular automaticamente o nível de risco pela metodologia HRN (Hazard Rating Number). Implementação de captura de imagens pela câmera ou galeria com compressão automática, assinaturas digitais do auditor e do responsável pelo local, e fluxo de inspeção com status de rascunho e finalizada. Geração de relatórios profissionais em PDF, com logotipo e dados personalizados da empresa, e exportação de planilhas CSV compatíveis com Excel. Persistência e armazenamento em nuvem com Supabase (PostgreSQL) e navegação com Expo Router.

\textbf{Site para Hotdogueria (Rock Dog) – Next.js, Vercel} \\
Desenvolvimento, com apoio de ferramentas de IA, de site responsivo para uma hotdogueria de Mandaguari, com o objetivo de facilitar o fluxo de clientes e pedidos. O site apresenta cardápio com filtros por categoria (simples, duplo e vegano), carrinho de pedidos, seção institucional, avaliações de clientes e informações de horário, endereço e formas de pagamento, com integração aos canais de atendimento do negócio (WhatsApp, iFood e Instagram). Publicado na Vercel: \href{https://rock-dog-dogueria-mqwp.vercel.app/}{rock-dog-dogueria-mqwp.vercel.app}.

\textbf{Connect API – Java, Spring Boot, MongoDB} \\
Desenvolvimento de uma API REST voltada para interação entre usuários e publicações, permitindo cadastro de usuários, criação de posts e adição de comentários. A aplicação foi construída com Spring Boot e Spring Data MongoDB, utilizando modelagem NoSQL com documentos embarcados para comentários e referências entre usuários e posts. Implementa consultas textuais avançadas com regex, filtros por intervalo de datas e busca em campos aninhados, além de arquitetura em camadas, DTOs para otimização dos dados trafegados e endpoints CRUD em JSON, com gerenciamento do projeto via Maven.

\textbf{API de Gestão de Vendas – Java, Spring Boot, Spring Data JPA} \\
Desenvolvimento de uma API REST em Java com Spring Boot para gerenciamento de usuários, pedidos e produtos. O projeto utiliza Spring Data JPA e Hibernate para persistência de dados, com modelagem de relacionamentos entre entidades e uso de chave composta para itens de pedido. Inclui endpoints CRUD em JSON, banco H2 para testes e suporte a PostgreSQL, seguindo arquitetura em camadas (Controller, Service e Repository) e build com Maven.

\textbf{Automação de Planilha + Integração com API - Python, Pandas, OpenPyXL} \\
Desenvolvimento de aplicação em Python para automatizar o processo de atualização de planilhas Excel, integrando com uma API que entrega os dados atualizados da Tabela do Brasileirão, eliminando tarefas manuais repetitivas e reduzindo riscos de erro na manipulação de dados. O projeto processa dados por meio de um serviço principal e atualiza diretamente uma aba existente, preservando a estrutura original do arquivo sem recriá-lo. Inclui validação de existência de arquivos, organização modular do código e geração de executável para distribuição sem necessidade de ambiente Python instalado.
