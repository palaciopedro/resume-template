\section{Projetos}
\textbf{Safety Inspect – React Native, Expo, TypeScript, Supabase} \\
Aplicativo mobile para gestão de inspeções de Segurança e Saúde no Trabalho (SST), com cálculo automático de risco pela metodologia HRN, registro de ocorrências com fotos (câmera ou galeria, com compressão) e assinaturas digitais. Gera relatórios profissionais em PDF com logotipo da empresa e exporta planilhas CSV compatíveis com Excel. Dados armazenados em nuvem com Supabase (PostgreSQL).

\textbf{Site para Hotdogueria (Rock Dog) – Next.js, Vercel} \\
Site responsivo, desenvolvido com apoio de ferramentas de IA, para facilitar o fluxo de clientes e pedidos de uma hotdogueria de Mandaguari. Inclui cardápio com filtros por categoria, carrinho de pedidos, avaliações de clientes e integração com WhatsApp, iFood e Instagram.

\textbf{Connect API – Java, Spring Boot, MongoDB} \\
API REST para interação entre usuários e publicações, com cadastro de usuários, posts e comentários. Utiliza Spring Data MongoDB com modelagem NoSQL (documentos embarcados e referências), consultas com regex, filtros por intervalo de datas, arquitetura em camadas, DTOs e gerenciamento via Maven.

\textbf{API de Gestão de Vendas – Java, Spring Boot, Spring Data JPA} \\
API REST para gerenciamento de usuários, pedidos e produtos, com persistência via JPA e Hibernate, relacionamentos entre entidades e chave composta para itens de pedido. Banco H2 para testes, suporte a PostgreSQL e arquitetura em camadas (Controller, Service e Repository).

\textbf{Análise de Vendas de Videogames - Python, Pandas, Matplotlib} \\
Análise exploratória de dataset de vendas de videogames no Google Colab, com tratamento de dados ausentes (reconstrução de vendas regionais a partir do total global), remoção de inconsistências e criação de variável de década. Agregações por plataforma, gênero, publisher e região, com visualizações em gráficos de linha, barras e pizza.
